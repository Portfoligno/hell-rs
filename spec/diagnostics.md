# Diagnostic codes

- `H0001` source read failure
- `H0002` source is not UTF-8
- `H0100` lexical/layout failure
- `H0200` syntax or unsupported surface form
- `H0300` duplicate or cyclic declarations
- `H0400` name-resolution or unavailable primitive failure
- `H0500` type inference/unification failure
- `H0701` missing `main`
- `H0702` `main` is not `IO ()`
- `H0703` independent core verification failure
- `H0900` guest runtime failure
- `H9000` internal invariant failure
